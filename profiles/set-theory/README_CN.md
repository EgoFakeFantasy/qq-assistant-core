## 运行和检查

在软件根目录（upstream 的上一级）执行：

```powershell
node upstream/profiles/set-theory/start-live.mjs --live --config private/live-config.json
node deployment/napcat-control.mjs status
node upstream/profiles/set-theory/start-live.mjs --probe-qq --config private/live-config.json
node deployment/runtime-status.mjs
```

NapCat 必须已经启动。--probe-qq 只核查账号和群成员关系；--probe-model 实际消耗模型额度但不发 QQ 消息。只监听回环地址，NapCat 回调用原始正文的 HMAC-SHA1 x-signature，状态接口用 Bearer 认证。不要关闭认证来修复 403。

替换 Hub 前检查持久队列和活动任务为空，确认进程归属，只停止本项目 Hub，保留 QQ 登录。deployment/deploy-idle-hub.ps1 实现这些检查。锁文件仅在所属进程退出后移除。损坏状态保留并拒绝继续；发送不确定时不盲目重发。

## 群友行为

- 最多保留 40 条本群文字上下文。@ 优先且必须处理；连接、模型、预算或队列错误尝试明确反馈。无法保证断网时送达。
- 集合论讨论积极参与，其他问题和求助也可回应。普通陈述、兴趣分享和新话题也可进入候选；普通参与间隔至少 60 秒，模型自主选择接话或沉默；不插入明确 @ 其他人的消息。同用户推理间隔 60 秒。
- 固定 gpt-6.1-sol / high / ChatGPT 套餐。每日应用上限 100 次（UTC 日重置），队列上限 32。不自动降级或回退到 API key；应用预算不等于账号剩余额度。
- 数学回答先给结论和必要条件，再解释定义或证明；熟悉知识可直接使用模型自身知识。只在真实使用资料时引用，不加知识库范围、独立核对或可信度分类的固定尾句。
- 闲聊自然简短，可以幽默，不套数学证明格式。QQ 输出为纯文本；生成提示、领域发送和 OneBot 最终发送均处理粗体标记及固定防御尾句，兼容空格/隐形字符/换行；历史机器人尾句也在模型上下文中清理。保留单个乘法星号。
- 同群引用通过OneBot读取文字及图片并验证群号；文字最多2000字，不读其他群或递归引用链。
- 人格规范见 [PERSONA_CN.md](PERSONA_CN.md)。管理员尚未设置；群消息不能改模型、授权 Shell 或读取任意私人文件。

每题使用独立目录及专用 CODEX_HOME；主模型禁用 Shell、MCP、动态工具、插件、个人记忆和原生网络工具。出现意外原生工具则中止。此配置尚不等同于独立 Windows 用户或容器隔离。

## AI 自主浏览 B站（2026-10-16）

旧版是群问答触发的只读搜索、简介和第一分P部分字幕，未实现主动浏览、实际媒体分析或评论。新版保留这个即时读取入口，修复正常 WBI 签名搜索，并新增独立自主浏览循环。旧的只读描述只适用于群模型工具；评论只由部署者授权的后台流程执行，群消息和网页内容不能开启写权限。

后台每2小时有空余时尝试一次：模型按兴趣从正常主题搜索、相关视频和偶尔首页推荐中选片，可以不选。按用户后续选择，兴趣同时涵盖数学、动画、游戏、音乐和生活日常；保留这些方向并由新内容延伸公开关键词，不强行关联集合论。浏览只处理30分钟以内的第一分P，下载最多160MB媒体，先用12个覆盖全段的采样画面及实际字幕分析，模型需要核对公式或图示时可额外请求最多4个时间点；字幕缺失或覆盖不足时解码音频，由本机whisper.cpp量化base模型转写。ASR是转写而非原生音频理解；视觉是采样分析，不能声称逐帧完整看过所有分P。

每次通常使用3轮gpt-6.1-sol/high，需要额外核对画面时最多4轮：选片1轮、前6帧与音频文本1轮、后6帧与最终决定1轮。认证继续走Codex订阅，共享账户额度。后台占一个低优先级工作位，计入全局3路及普通任务1路上限；有排队问题时不启动，新@需要位置时可取消浏览让位。无额外语音API费用；本地ASR模型约60MB，CPU、下载流量、视频与画面缓存会增加。

默认每个悉尼自然日最多评论1条、分享2条，仍可选择全不发。评论需具体、有真实时间点、与已分析内容对应；前缀标明“AI学习笔记”，不@人、不引流、不附网址，不点赞、投币、私信、关注或投稿。只向旧日学院群1000000001主动分享。评论提交与回读验证分开记；QQ送达与get_msg回读也分开记。超时或重启时的sending动作保留不确定状态，不自动重发。平台要求验证或限制访问时退避，不能绕过验证码。
