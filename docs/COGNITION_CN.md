# 注意力与经过审核的人格演化

## 设计与来源

这是参考 [dd19-bot](https://github.com/42Noveland/dd19-bot/tree/d1924f37a4c87c4e5eb3229825ca2dc042664015) 后独立编写的 JavaScript 实现。已审阅其 MIT 许可的 `bot/plugins/auto_chat.py`（廉价预筛、冷却、按发言者续接、保守接话）和 `bot/core/persona_evo.py`（待审建议、批准、独立补充、回滚）。没有安装第三方程序，也没有复制其源码或人格文本。

现有递归人格总结器 `src/qq-self-persona.js` 仍属于证据生产环节；不能把它生成的自由文本直接交给审核模块当系统指令。现有群/成员记忆继续提供来源。新增模块负责注意力准入与审核，不负责独立证明事实，也不是第二份机器人实现。

## 注意力

`src/domain/cognition/attention.js` 是不调用模型、不联网的确定性筛选器。宿主先检查账号、群、当前真实@和回复规则。`eligible=false` 始终拒绝；已经通过回复授权的明确请求不需要积累兴趣分。普通接话需要话题、问题、称呼或已确认送达的同成员近期回复，不能仅因闲聊字数长就介入。

兴趣分在十分钟内衰减。普通接话遵守原有冷却、每群十分钟最多三次的预算及重复文本抑制。对话续接最多两分钟，也不能绕过冷却和群预算。失败/不确定的发送不建立续接窗口。宿主在去重后调用筛选器，将返回状态与队列一起持久化，只在确认送达后调用 `attentionReply`。状态仅含有界计数、时间与指纹，不保存原聊天。恢复时检查数值范围。档案通过 `attention.enabled=true` 开启；省略/false 保持原有接话方式。

## 审核与递归反馈

`src/domain/cognition/persona-review.js` 接受宿主核验过的候选：固定表达主题、群、成员、人格、核心版本、到期时间、证据编号。至少需要跨两天、三个独立时段。宿主必须从实际核验的人类证据计算次数，不能信任模型自报的次数。被拒绝、已撤回或存在相反证据的记录不能作为有效候选；机器人自己的输出、检索所得记忆及先前补充不能自我强化成人类证据。

流程为待审→批准/拒绝；批准后可回滚或失效。每次操作都检查预期修订号，并保留有界审核记录。每群、成员、人格最多两项生效补充。核心版本改变、证据到期/撤回、证据指纹改变，会立即使旧补充停止进入请求。拒绝与回滚不会自动撤销。

实际补充只能取部署者维护的 `styleThemes` 固定表达。人类或模型的自由文本不能成为提示词补丁。核心身份、模型选择、权限和数学正确性不属于这一表达调整层。`selectPersonaRequest` 按实际路由的人格选择记忆和补充，在调用提供方前移除其他人格的数据包。人格、群、成员和私信范围继续隔离。

公开仓库包含可复用模块、测试和原有教学档案的可选注意力接入。私有记忆/提供方/审核接口接入及运行数据不在公开导出中。不能据此认为所有旧调用者已经自动受新审核机制管辖：宿主仍须明确连接经核验的候选生产器和审核边界。

## 本机部署接入

现有本机群记忆分别生成两个人格的候选。`personaEvolution.enabled=true` 在原记忆旁启用 `persona-review.json`；启动时不改写核心人格文件或既有原始证据。私有部署通过当前私有档案开启两个开关，不用公开默认档案覆盖它。

经过认证的本机 POST `/api/maintenance/persona-review` 接受 `groupId`、`persona`、`action`（`list`、`approve`、`reject`、`rollback`），决策还需 `id`、`expectedRevision`。未知字段被拒绝。群聊命令不会取得部署者审核权。列表只含固定候选表述与来源编号，应保留私有；诊断只暴露启用状态、数量和修订号。获批补充只用于本群、对应成员和人格。安装不会自动批准当前候选。

## 验证

`node --test test/cognition-review.test.js` 检查纯函数筛选、有界状态、审核、隔离、证据撤销和回滚。本机 `profiles/set-theory/cognition-integration.test.mjs` 还检查持久记忆、注入客户端下的实际路由选择、受保护群真实@限制及审核接口认证。这些是离线夹具，不是真实模型或QQ群发送验收。运行仓库验证命令，并对照已有平台相关失败。只在 Hub 空闲或安全保存工作后重载，保留 QQ、知识库、私有配置和会话。不要向群发送合成测试消息。
