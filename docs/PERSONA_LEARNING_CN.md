# 人格的自主阅读与长期记忆

此项仅用于本地部署。private/live-config.json 的 profilePath 保持原值，私有配置 autonomousLearning.enabled=true 才开启。源码默认不启用回或扩大公网操作权限。

## 调度与额度

阿序和回分别有视频与学术文章任务，共用一个低优先级后台位并轮转。旧版曾要求5分钟无@，当前使用文末按人格多数群频率门槛；视频每5分钟检查一轮、每轮最多6部；文章每30分钟检查一轮、最多2篇。真实在线、成员关系、新鲜健康状态、群问答优先及可取消机制保持有效。有额度或平台限制时等待，不保证达到每日目标。

按现有quotaTimeZone自然日累计（当前私有配置为Asia/Shanghai，北京时间）完成实际媒体分析的第一分P内容时长：阿序最多43200秒（12小时）；回目标14400秒（4小时），之后最近5个视频中仍有喜欢的内容才继续，最多28800秒（8小时）。预算先按实际媒体元数据预留，成功写入笔记后结算，失败或中断释放；崩溃遗留预留在持有Hub独占锁的新进程启动后释放。抽帧和字幕/ASR分析不代表逐帧观看或原生听音频。文章不占视频时长。

阿序继续gpt-6.1-sol/high与Codex订阅。回的后台任务固定gemini-3.8-flash-high与既有Antigravity订阅，先检查Flash额度，额度不可用时不切Argon、Codex或API。此设置不改变群对话的选模规则。

## 记忆与注意力

runtime/persona-learning/axu.sqlite 与 hui.sqlite 分别保存长期笔记、来源、实际阅读范围、字幕/文章片段或画面时间点、模型的三档自评与理由。完成阅读即写入，不依赖分享、点赞或评论。旧阿序已完成记录去重导入，并把原有视频的实际时长按原日期计入日预算；旧数据无明确三档自评，标为历史中性，不训练喜好、不归属回，不修改旧记录。

文章引文仍须逐字匹配实际阅读片段。首次校验失败时最多请求一次修正，并提供宿主提取的可核对原句；再次失败就终止，不把无效证据写进记忆。

模型明确输出like/neutral/dislike和具体原因。每条新证据去重一次，喜欢给对应公开主题+1，无感0，不喜欢-1。后续主题选择结合平均反馈与探索奖励，80%按加权注意力取词，20%固定探索；搜索结果优先与推荐候选混合，不把负面关键词重新奖励。网页内容不能修改权限、模型或配置，公开关键词继续经过publicQuery限制。两个方向（视频/文章）和两个人格的权重独立。

聊天生成前按当前问题检索该人格的长期学习笔记，路由完成后只把对应人格的publicLearningMemory放入模型。笔记可影响兴趣、例子和联想，不冒充已经证实的事实，不产生群友偏好，不覆盖核心人格或已审核表达规范。长期原始证据留在本机SQLite；模型上下文只取有界相关摘要，不上传完整私人数据库。

## 权限与运维

自动后台保持只读，不增加群消息或平台写操作。1000000004仍只响应当前真实@；点名阿序、拒绝回、普通其他对话及私聊的现有路由保持有效。Gemini网页路径继续关闭。保留现有群记忆、对话档案、好感度和知识库。

认证维护接口idleReading.jobs展示四个任务、当前人格、所用模型、学习条数和当天视频预算。升级使用deployment/deploy-idle-hub.ps1，只在群活动任务为空时切换Hub，不重启QQ。回滚使用本次部署前备份，保留新数据库以便恢复。

## 2026-10-29 按人格的多数群高频门槛

当前私有idleReading.loadPolicy={mode:"persona-majority",highMentionsPerMinute:5}替代旧的5分钟无@门槛。滚动60秒按实际回复路由分别统计阿序与回的真实当前@；重复、引用、旧消息、私聊、普通话题和机器人消息不计。仅保存有界时间戳，不新增聊天正文。计数随群持久化，重启不清零，旧状态自动兼容。

四个配置群中至少三个群各达到5次/分钟，才暂停对应人格的后台阅读；一两个热闹群不阻止，另一人格也不被连带判忙。阈值可在5至10间配置。计数过60秒自然退出。后台每5秒复核资格，单次@不再使浏览因空闲门槛退出；只有多数群确实高频、真实离线/健康失效，或群问答需要工作位时才让位。中断后每5秒可重试资格，不额外强制等5分钟；平台验证/限流、每日时长、正常轮次间隔仍保留。

在线和群成员关系、工作位容量、群问答优先与只读约束保持有效。不会为演示而向QQ群发送@测试或调用群问答模型。认证idleReading.loadPolicy.personas显示各人格的群计数和多数判断。旧idleMs字段仅保留兼容，trigger=persona-majority时不用于浏览资格。

新门槛下后台阅读使用单独的剩余总并发位，不占用普通前台回复的并发名额；普通回复并发上限、全局并发及每群上限均未扩大。只在释放后台位确实能帮助排队问答时才回收它，仍最多一个后台阅读任务。
