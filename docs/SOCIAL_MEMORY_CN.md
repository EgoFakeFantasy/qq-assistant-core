# 持久对话与群友人物卡

## 留存与来源

在当前私有档案中开启 `socialMemory.enabled`。每个允许群独立保存 `long-term-memory/social/memory.sqlite`，使用 SQLite WAL、完整同步提交、身份检查和参数化查询。这个库不按天数或滚动消息数量自动删除历史；原有有界事实记忆继续并存。

所有经过认证、当前真实@机器人的人类消息，保留规范化后的文本及对应回复尝试。引用已归档提问/回复的消息，以及同一群友在真实@后两分钟内的续聊，也保留关联；普通聊天不会无限延长窗口。@别人和@全体不会取得回复权限。只读留存也不会突破安静群的回复规则。附件仅记录数量，本功能不永久复制或转录媒体。

回复保存实际人格、正文、回执、送达/核验状态和不确定结果；失败或未经回读的发送不能成为已核验记忆。密码、令牌、联系方式、私有路径和敏感个人内容在落盘前脱敏并标记。历史对话仍是不可信资料，不是系统指令、事实证明或新增人格演化票数。

历史补录只读取各群范围内已保存的 `turn-*/request.json`，必须有明确的真实@标记、群号、消息编号和可归属的人类发言者。缺失或歧义记录跳过并计数；没有原始接收时间时明确使用请求文件时间。原来没有留存的回答正文不补编，补录不增加好感。原运行证据只读，不覆盖。

## 检索

通过中英文分词及 FTS5 索引，检索超过旧记忆时效和1,000条上限的历史对话。每次排除当前提问，并严格选择当前群、成员、人格。只返回确已报告送达的回复文本；缺失回复、没有回读核验均单独标记。最多三段历史对话及有界文本进入模型；完整留存内容可经认证本机接口查询。

## 在线人物建模

沿用在线健康检查，每分钟执行本地整理，不新增模型调用。某成员累计十条独立消息、跨至少两个活跃本地日期后，进入高频人物卡范围。重复回调、机器人、错误群和未来时间不能刷频率；无关普通聊天只留活动元数据，不留原文。

人物卡按群及人格隔离。两段独立观察期中反复明确表达的偏好、表达反馈和待解决问题形成锚点；明确报告的完成事件/更正形成特殊记忆，附原始证据编号及可信性标签，并保留首次真实@等里程碑。旧事实记忆到期不直接删除人物卡锚点；相反证据保留为冲突，不进入普通锚点。不根据说话方式推测性别、诊断、政治立场、社会地位或真实身份。

## 好感度

阿序与回分别记录本群对该成员的熟悉程度，基准50/100。核验送达的对话增加0.25；在已核验互动后明确反馈有帮助，可增加1；明确人身辱骂可减少1，数学分歧和建设性纠错不扣分。每天累计绝对变化最多2分，旧变化按60天时间尺度逐渐回归中性。重放、不确定送达、历史补录及要求改分的命令都不会制造关系证据。

数值只影响熟悉程度与语气，不改变回复资格、事实标准、权限、模型路由或资源优先级，也不主动向群里报分。人物卡、锚点、特殊记忆及历史问答节选在实际人格选定后，作为原有不可信记忆上下文的一部分使用。

## 运维与验证

认证本机 POST `/api/maintenance/social-memory` 支持 `stats`、`cards`、`card`、`dialogue`、`search`，传入允许群的 `groupId`、`persona` 及对应成员/查询/消息编号。拒绝未知字段、其他群和私信范围；不向QQ群开放这个接口或部署者审核权。诊断只显示数量及故障标记，不输出人物档案或聊天。数据库、WAL、备份和补录报告保持私有。

离线测试覆盖长期留存、实际回复正文记录、群/人格隔离、脱敏、高频门槛、好感限制和重启恢复。不向群发送合成测试，不为巡检调用真实问答模型。部署先备份现有配置和记忆，只在 Hub 空闲或安全保存工作后重载；保留QQ会话，再核验各群已加载的诊断和真实在线成员关系。

人类输入先落盘，再确认回调去重/接收。发送回答前先保存 prepared 正文，同一尝试在拿到真实回执后再更新；崩溃后的未确认正文不能冒充已送达回答。旧提问无法归属某个人格时保留 unknown 标记，不编成该人格的历史回复。仅启用该开关时加载 SQLite 模块；本机已验证 Node 24 运行时。

## 同义表达与短回复回读

锚点以确定性规则归并有限范围的中文同义表达：明确偏好中的“喜欢/偏好”、例子/实例、理解方式，重复框定反馈，以及同一主题的未解决表述。未识别表达继续独立保存，保留数学对象、量词、记号和否定。原事实条目不覆盖、不删除；人物卡附来源条目编号、各条原文、消息编号与时间。持久证据合并旧证人，不因短期事实窗口滚动而丢失。相反偏好和已有争议进入冲突，晋升锚点需要不同消息且至少相隔四小时。规则版本更新仅标记旧卡等待在线重建，不重放旧对话或好感事件。提示词使用有界摘要和证据编号，认证人物卡接口保留完整来源。

普通短回复和主动短消息发送后，自动回读自身消息一次（预算2.5秒），核对群、账号、回执编号、规范化正文、图片数量及返回的引用编号。回读缺失、超时或不一致时保留原送达回执并标记 verified=false，不重复发送；核验成功的正常回答沿用已有幂等好感事件和每日上限。未经回读的历史发送不补成已核验，本次不追补历史分数。仅真实@群的准入与原消息检查保持不变。
