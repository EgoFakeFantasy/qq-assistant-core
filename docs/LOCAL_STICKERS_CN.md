# 本地可爱表情

QQ 回复、主动推荐和 B 站评论共用表达原则，发送前替换具有嘲讽或攻击意味的反应表情。可以少量使用温和颜文字，但不要求每条回复加表情；数学证明不强行装饰。

表达情绪的本地图片只能从部署者审核过的目录中选择。普通聊天可以附一张本地可爱表情，不需要先发搜图指令；每条最多一张。网页图片仍需明确搜图请求，并保留原有来源说明。

默认目录为主运行目录旁的 private/stickers/catalog.json；也可在私有运行配置中设置 localStickerRoot。三个群有意共用这一审核素材目录，题目工作目录和群资料仍各自隔离。

目录格式：

```json
{
  "version": 1,
  "stickers": [{
    "id": "sticker-smile",
    "file": "smile.jpg",
    "title": "友好微笑",
    "tags": ["招呼", "微笑"],
    "reviewed": true,
    "tone": "cute",
    "sha256": "填写实际审核图片的64位SHA256"
  }]
}
```

添加前逐张查看图片及文字。文件名只接受当前目录内的 PNG/JPEG，最大 4 MiB，并记录实际 SHA-256；拒绝符号链接、任意路径、未经审核的项目及已知攻击性标签。选中后再次核验哈希，并复制到当前题目工作目录。目录缺失或无有效项目时不提供图片，正常文字回答继续工作。

模型只获得 id、描述及标签，不获得来源路径或整个 QQ 图片缓存。不要自动开放所有收到的图片。修改目录后在 Hub 空闲时重载，保留正在进行的回复、QQ 登录和知识库。实际素材与目录保持私有；公开测试只使用合成图片。
