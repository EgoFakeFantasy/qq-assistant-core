# 长期记忆与人格候选

[English](LONG_TERM_MEMORY.md)

同群长期记忆参与回答；人格只生成候选，不自动应用。本功能不改模型、路由、工具权限或群回复规则。

## 收集与证据质量

鉴权、消息归一化、机器人过滤和去重后才观察人类文本。收集不调用额外模型、不发送消息；mentions-only 群的非 @ 消息仍不回复。正常回答可返回最多三条当前消息的逐字安全片段。

偏好和表达反馈按群及成员隔离；纠错、暂定说法、事件和未完问题只在本群召回。普通定义或“应该是……”归为 claim，不能冒充明确纠错或已核验知识。事件须有明确事件及完成陈述；旧的证据不足记录保留原证据，但不参与召回。直接引用、凭据、URL、路径、权限和人格修改命令不进入记忆；这是保守过滤，不是任意恶意自然语言的安全证明。

新记忆逐字保留数学 Unicode 原文；规范化仅用于安全检查与词项匹配，不改写 ℕ、𝒫 等符号。

## 存储与候选

每个群的运行目录有独立 long-term-memory/。memory.json 最多1000项、3 MiB，串行原子写入；损坏或链接文件拒绝加载，不清空覆盖。Windows 暂时共享锁只做有界重试。偏好及表达反馈保留90天，新的 claim 和未完问题30天，明确纠错和有效事件60天。旧版记录保留原到期时间。召回和机器人复述不会续期。

状态接口只给出计数、质量拒绝计数和故障状态，不暴露正文。reviewPending 表示暂不参与召回的旧事件，claims 包括旧记录的展示分类。已有原文和来源不因打开新版本而重写。冲突保留双方，不由记忆系统裁决数学事实。

persona.candidate.json / persona.candidate.md 从阿序的明确表达反馈生成：同一成员至少3个不同4小时时段、跨2个悉尼日期。每份最多2项，标注 member-in-group 与需反证检查。回的反馈不强化阿序；候选从不进入提示词，不写入 persona.md 或人格模板，autoApply/applied 始终为 false。没有充分证据就保持空候选。

## 本地回放

发布版可用 npm run replay:memory -- --input private/events.jsonl --out-dir private/replay-new --bot-id BOT_ID。输入每行是有真实来源的本地事件对象：groupId、senderId、messageId、text、at；at 为毫秒时间。输出目录必须新建且位于 private 内。先查询再观察当前消息，末25%作为后段查询；不调用模型、网络或 QQ 发送。报告只有聚合数字，提取的记忆仍是私有材料。

开发时比较了1,666条历史请求、418次后段查询：改前改后均4次召回命中，无跨群、跨成员、当前消息或未来消息泄漏。现存10条记录中，6条展示为暂定说法、3条旧事件暂不召回，原证据未改。历史来自保存的请求快照，并非完整群聊；规则在这批数据上改进过，因此不是独立盲测，也不证明回答准确率改善。真实群聊、回放原文和私有验收报告不发布。

## 验证与运行

运行 npm run verify 和 npm run audit:public；记忆、路由及群策略有独立合成回归测试。重载只能在 Hub 空闲时进行，保留 QQ 会话、私有 profilePath 和各群设置。默认主模型 gpt-6.1-sol/high；回只由当前真实 @ 加明确称呼触发。候选不会自动生效。
